## 项目概述

**资本持久战** 是一个基于 TypeScript 的模拟框架，旨在通过蒙特卡洛实验验证 Anti-Martingale 仓位管理策略与不同交易信号策略结合的有效性。

### 为什么叫"持久战"？

名称源于毛泽东《论持久战》的战略思想——通过耐心、韧性和长期复利积累小优势来取得最终胜利，而非追求即时的决定性结果。在交易中，这意味着：

- 不追求单次交易的暴利
- 通过高胜率策略积累连胜
- 利用 Anti-Martingale 将连胜转化为指数级增长
- 地板保护确保永不归零

---

## 核心概念

### Anti-Martingale 规则

与传统 Martingale 策略（亏损后加倍下注）相反，Anti-Martingale 采用"赢了加注，输了收手"的原则：

| 交易结果 | 下一步行动 |
|----------|------------|
| 盈利 | 仓位翻倍 |
| 亏损 | 重置为基础仓位 |

**为什么有效？**

- 连胜时仓位指数增长：1x → 2x → 4x → 8x → 16x...
- 单次亏损仅损失当前仓位，不会伤及本金
- 将"运气好的时候"的收益最大化

### 资产倍数 M

核心追踪指标是 **M**（峰值资产倍数），表示相对于初始资本所达到的最大资产比率。

```
M = max(资产历史最高点) / 初始资本
```

### 地板保护

系统在 M=1 处维持"地板"保护机制：

- 利润逐步锁定，只升不降
- 永远不会损失超过初始资本
- 在限制下行风险的同时捕获上行收益

## 实验设计

### 实验1：基础验证

**目的**：验证 Anti-Martingale 在不同波动率下使用随机信号（对照组）的表现。

| 参数 | 设置 |
|------|------|
| 市场模型 | GBM（几何布朗运动） |
| 信号策略 | 随机（~50% 胜率） |
| 波动率 | 1%, 5%, 10%, 20%, 50% |
| K线数量 | 2,000 |
| 蒙特卡洛次数 | 1,000 |

### 实验2：信号策略对比

**目的**：对比不同信号策略在各种波动率/杠杆场景下与 Anti-Martingale 结合的表现。

**四种信号策略**：

| 策略 | 原理 | 预期胜率 |
|------|------|----------|
| 趋势跟踪 | MA(5) 上穿 MA(20) 做多 | ~35% |
| 均值回归 | 价格低于均线买入，高于均线卖出 | ~70% |
| 突破策略 | 突破价格通道时交易 | ~35% |
| 随机策略 | 对照组 | ~50% |

**六种波动率场景**：

| 场景描述 | 基础波动率 | 杠杆 | 等效波动率 |
|----------|------------|------|------------|
| 低波动资产（股票/外汇） | 10% | 1x | 10% |
| 中波动资产（小盘股） | 20% | 1x | 20% |
| BTC 现货 | 50% | 1x | 50% |
| BTC 2倍杠杆 | 50% | 2x | 100% |
| BTC 5倍杠杆 | 50% | 5x | 250% |
| BTC 10倍杠杆 | 50% | 10x | 500% |

### 实验3：市场类型对比

**目的**：测试 Anti-Martingale 在不同市场动态模型下的表现。

- GBM（独立同分布收益）
- GARCH（波动率聚集）
- 趋势市场（带漂移项）
- 均值回归市场

### 实验4：全矩阵扫描

**目的**：波动率 × 市场类型 × 信号策略的全面组合测试。

## 关键洞见

### 洞见1：策略-波动率协同效应

**高胜率策略 + 高波动率 + Anti-Martingale 的组合能创造爆发式增长。**

均值回归策略实现约70%胜率，与 Anti-Martingale 的赢后加倍机制结合时，创造强大复利效应：

- 每次连胜仓位翻倍：1x → 2x → 4x → 8x → 16x → 32x...
- 在70%胜率下，长连胜序列很常见
- 均值回归的平均最大连胜次数：11-13次
- 仅需7次连胜即可实现 128 倍收益

### 洞见2：波动率是必要但非充分条件

**更高波动率会放大结果，但没有策略优势（>50%胜率），不会产生实质性增长。**

| 条件 | σ=10% | σ=50% | σ=500% |
|------|-------|-------|--------|
| 随机策略（50%胜率） | 1.00x | 1.02x | 1.24x |
| 均值回归（70%胜率） | 186x | 82,825x | 87,753x |

这说明：
- 波动率提供了增长的"燃料"
- 但只有胜率>50%才能点燃这个燃料
- 胜率越高，燃烧效率越高

### 洞见3：杠杆归一化原则

**不同资产在不同杠杆下可通过等效波动率进行横向比较。**

- BTC 现货（σ=50%）≈ 股票 5倍杠杆（σ=10% × 5 = 50%）
- 山寨币现货（σ=100%）≈ BTC 2倍杠杆
- 交易成本随杠杆倍数线性放大

### 洞见4：M 的重尾分布特性

**资产倍数 M 的分布呈现明显的重尾特征，少数路径贡献了绝大部分期望收益。**

以均值回归 σ=50% 为例：
- 中位数 M：140x
- 平均数 M：82,825x
- 最大值 M：23,795,524x
- 95分位数：37,800x

这意味着：
- 大多数情况下能获得稳健的正收益（中位数140倍）
- 少数"幸运"路径可以获得极端收益
- 期望值被少数极端值显著拉高

### 洞见5：胜率阈值效应

**存在一个明显的胜率阈值（约55-60%），低于此阈值 Anti-Martingale 效果有限。**

| 胜率区间 | 典型策略 | Anti-Martingale 效果 |
|----------|----------|---------------------|
| <50% | 趋势跟踪（34%） | 微弱正效果 |
| ~50% | 随机 | 几乎无效果 |
| 50-60% | 突破策略 | 中等效果 |
| >60% | 均值回归（70%） | 爆发式增长 |

## 复现实验

### 环境要求

- Node.js >= 18.0
- npm 或 yarn

### 安装步骤

```bash
# 克隆仓库
git clone https://github.com/your-username/CapitalProtractedWar.git
cd CapitalProtractedWar

# 安装依赖
npm install
```

### 运行实验

#### 运行单个实验

```bash
# 实验1：基础验证（随机信号 × 5种波动率）
# 预计时间：~1分钟
npm run exp1

# 实验2：信号策略对比（4种策略 × 6种场景 = 24种配置）
# 预计时间：~5分钟
npm run exp2

# 实验3：市场类型对比（4种市场模型）
# 预计时间：~1分钟
npm run exp3

# 实验4：全矩阵扫描（波动率 × 市场 × 信号 = 24种配置）
# 预计时间：~5分钟
npm run exp4
```

#### 运行全部实验

```bash
# 一次性运行所有实验（预计总时间：~12分钟）
npm run exp1 && npm run exp2 && npm run exp3 && npm run exp4
```

## 局限性

1. **模拟市场**：使用合成价格数据（GBM/GARCH），非真实市场数据
2. **无滑点**：假设以市价完美成交
3. **固定参数**：信号策略参数未经过优化
4. **无仓位上限**：假设可无限扩大仓位
5. **无资金费率**：杠杆场景未计入持仓成本
